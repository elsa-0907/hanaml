ARCHITECTURE

How It Works

An end-to-end natural language processing pipeline optimized for lightweight, low-latency SMS threat classification.

01

Message Input

Raw SMS text is received through a secure POST request, normalized, and pre-screened for encoding and length constraints.

02

TF-IDF Vectorization

Text is tokenized, stripped of English stop words, and mapped into unigram and bigram numerical vectors using sublinear term-frequency weighting across 10,000 vocabulary features.

03

LinearSVC Decision

A Linear Support Vector Classifier with balanced class weights projects the sparse vector against an optimized maximum-margin hyperplane separating spam from benign distributions.

04

Predicted Classification

The model produces a deterministic binary label (spam or ham) paired with actionable cybersecurity guidance.

SPECIFICATIONS

About This Project

SMS Spam Shield is a specialized cybersecurity machine learning application engineered to detect deceptive, fraudulent, and unwanted mobile text messages.

The classification pipeline was trained in Google Colab using scikit-learn and serialized with Joblib into an encapsulated production bundle (spam_model.pkl).

Model Pipeline
sklearn.pipeline.Pipeline
Feature Extractor
TfidfVectorizer(max_features=10000, ngram_range=(1,2), sublinear_tf=True)
Classifier
LinearSVC(class_weight='balanced')
Class Labels
['ham', 'spam']

Data Privacy & Handling Notice

Transparent disclosure regarding submitted message content

In-Memory Processing: When you submit an SMS message for analysis, it is transmitted over HTTP POST directly to the local Flask application. The backend vectorizes the text in RAM and executes the LinearSVC decision function.

No Message Storage: The message content is never stored in a database, never written to disk, and never preserved in server access logs. Once classification completes, the message is released from memory.

No Third-Party Retraining: Analyzed messages are not sent to any external commercial cloud APIs or used to retrain the model.
